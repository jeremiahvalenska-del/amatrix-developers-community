Rubriques d'aide

Questions fréquentes

Comment gérer mon profil ?

Ouvre Profil depuis le menu. Si la page n'est pas encore disponible, contacte l'assistance.

Comment trouver un livre ?

Ouvre Bibliothèque et utilise sa recherche. Le téléchargement dépend de la disponibilité du document et des autorisations associées.

Que faire si un générateur ne fonctionne pas ?

Vérifie les champs obligatoires, puis réessaie. Si le problème persiste, décris-le dans le formulaire ci-dessous.

Comment vérifier un paiement ?

Vérifie d'abord l'état de la transaction auprès de ton opérateur ou du prestataire officiel. Une demande affichée dans le navigateur ne prouve pas qu'un paiement a été effectué.

Comment suivre une commande ?

Consulte la rubrique Commandes si elle est disponible. Garde ta référence de commande pour toute demande d'aide.

Comment protéger mon compte ?

Ne partage jamais ton mot de passe ou ton code PIN Mobile Money. Utilise uniquement les pages officielles pour toute confirmation sensible.

Contacter l'assistance

Décris le problème. Le formulaire enregistre ta demande sur cet appareil ; l'envoi à l'équipe nécessite un service connecté.
